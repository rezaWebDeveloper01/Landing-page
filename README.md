# 🚀 Futuristic Landing Page

> 🎨 **Demo Project** — This is a front-end demo project created for learning, practice, and portfolio purposes. It is not a real commercial website.

---

## 🇬🇧 English

A modern, responsive and interactive landing page built with **HTML, CSS, and JavaScript**, featuring a futuristic dark/neon-purple visual style.

### ✨ Features

- 🌌 Futuristic dark/neon-purple UI
- 📱 Responsive design for desktop, tablet, and mobile
- ✨ Animated hero section with stars, grid floor, and orb
- 🧭 Responsive navigation bar
- 🎨 Custom CSS animations and visual effects
- 🃏 Interactive cards with hover effects
- 👀 Scroll reveal animations
- 🖱️ Interactive card spotlight effect
- 🎞️ Interactive projects slider
- 📩 Contact section
- ⬆️ Back-to-top button
- ♿ Reduced-motion support

### 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

### 🎯 Purpose

This project was created as a **front-end practice and portfolio project** to improve my skills in:

- Responsive web design
- Modern CSS
- CSS animations and transitions
- Interactive UI
- JavaScript interactions
- Clean and maintainable code
